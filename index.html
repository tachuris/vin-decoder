How the check digit is calculated+

The 9th character is a validity check defined by ISO 3779 / FIPS 115-1. Convert every character to a number, multiply by a fixed weight, and add the products. Divide the sum by 11: the remainder is the check digit, with 10 written as X. Position 9 has weight 0, so its own value never changes the sum — it simply has to match the result.

Digits keep their value. Letters are mapped as A=1 … H=8, J=1 … N=5, P=7, R=9, S=2 … Y=8. I, O and Q are excluded.
